# BudgetBuddy 💰

### A Full-Stack Personal Budget Planning and Expense Management Platform
BudgetBuddy is a personal finance management platform designed to help users (especially students) manage pocket money, track expenses, set savings goals, monitor spending habits, and generate financial reports for better financial discipline[cite: 1].
